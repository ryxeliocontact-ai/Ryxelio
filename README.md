## ✨ Fonctionnalités du site

- **Page unique** (one-page) en HTML / CSS / JavaScript natif — aucune dépendance, aucun build
- **Bilingue FR / EN** avec mémorisation de la langue (`localStorage`) et prise en charge de `?lang=en`
- **Design responsive** adapté mobile, tablette et desktop
- **SEO optimisé** : balises meta, Open Graph, Twitter Card, données structurées JSON-LD (Schema.org), SEO local (Tunis)
- **PWA-ready** : `site.webmanifest`, favicons et icônes Apple
- `robots.txt` et `sitemap.xml` pour l'indexation
- Sections : Services, Formations, Projets, Processus, Stack technique, Équipe, FAQ, Contact

## 🚀 Lancer le projet en local

Aucune installation n'est nécessaire. Clonez le dépôt puis ouvrez `index.html` dans votre navigateur :

```bash
git clone https://github.com/ryxeliocontact-ai/Ryxelio.git
cd Ryxelio
```

Ou lancez un petit serveur local (recommandé) :

```bash
# Avec Python
python -m http.server 8000

# Ou avec Node.js
npx serve .
```

Puis rendez-vous sur [http://localhost:8000](http://localhost:8000).

## 🌍 Déploiement
